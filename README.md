# Enterprise Lab

Year 2 cybersecurity student at Sunway University. Lab started October 2026.

A small company network I am building at home to learn how enterprise IT
works: Linux, Windows Server, Active Directory, networking and logging.

## What I plan to build
- An Ubuntu Server VM (users, permissions, services, SSH)
- A Windows Server domain controller with a Windows client joined to it
- One internal network connecting them, with a network diagram
- Central collection of login logs, and a Python script to analyse them
